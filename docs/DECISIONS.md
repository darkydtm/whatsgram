# Decisions

- Use the requested Go stack and pinned module versions; verify actual source APIs before selecting native support.
- Keep STATUS.md and DECISIONS.md as untracked coordination artifacts. Do not add either to .gitignore. SUPPORT_MATRIX.md is product documentation and may be committed.
- Create separate agent worktrees outside the repository so no ignore entries are needed.
- Preserve signed commits. A scratch gpg wrapper supplies an empty passphrase non-interactively; signing was actually verified for baseline 193d106.
- Explicit user authorization permits all local builds and tests for this project. CI remains a phase acceptance requirement.
- Use one self-contained executor per task; independent phase reviewers are explicitly required by the project specification. No extra planner hierarchy.
- No automatically published images, PRs, deployments, auto-merges or main-branch writes.
- Ruling: close fmt error-path token exposure by replacing raw string config token with an opaque type and explicit trusted runtime accessor - fmt invalid-verb diagnostics bypass Formatter/GoStringer, so raw fields cannot meet promised secrecy - cost if wrong: config programmatic callers change to accessor/constructor; no safety claim is silently weakened.
- Ruling: redact public sensitive domain JSON for ordinary nested structured logging, use explicit private persistence codecs so message payload is not lost; PairingNotice uses opaque PairingSecret with trusted Reveal - LogValuer/Formatter do not recursively protect containers or bad-verb fallback - cost if wrong: adapters/coordinator need explicit DTO marshaling, and private message raw-field programmer-error dumps remain prohibited rather than universally safe.
- Autonomous execution to MVP: complete all 6 phases autonomously without halting for routine approvals, enforcing the full criteria (TDD, independent reviews, clean CI, signed microcommits, isolated worktrees, zero plain secrets, zero em dashes, tabs for indent). Power off or suspend only upon complete verified MVP or an unresolvable blocker.
- Accept exact researched dependency pins: whatsmeow v0.0.0-20261014094007-f16f9ca30d6a, Telegram bot v1.27.0, modernc SQLite v1.60.1, YAML v3.0.5, Go >=1.26.0. Parent repeated real CGO-off source/schema/sqlstore probes with PASS.
- Ruling: implement concrete domain and structural storage APIs from accepted research, only tables actually needed by phases 1-3; add poll/identity-specific migrations later - reduce unused speculative framework - cost if wrong: later additive migrations.
- Ruling: uncertain Telegram creates and forum creation are quarantined by default, never blindly retried; operator-assisted bind or explicit warned retry is required - Bot API offers no create idempotency key/history search - cost if wrong: more manual recovery rather than hidden duplicate sends.
- Ruling: all allowlisted users are authorized operators in this initial config contract; ordinary original messages remain author-owned for edit/delete; the smallest allowed numeric Telegram user ID is the designated account reaction/vote driver, other intents use labeled fallback - satisfies explicit control allowlist and deterministic single-account conflict policy without surprise role source - cost if wrong: add explicit configurable operator/driver IDs later; removing the smallest ID changes driver after restart and must be diagnosed.
- Ruling: WA group title authoritative, topic manual names local aliases; closed topics pause, missing topics require explicit rebind/recreate generation - avoids infinite retry/recreation and deleting unrelated WA chats - cost if wrong: operator intervention on unavailable topics.
- Ruling: default history import none, partial chats from groups/history/new inputs; view-once metadata only, long disappearing deadlines warn or strict opt-in refusal - preserve privacy/API limits - cost if wrong: some content intentionally remains on source only.
- Ruling: WA pins/poll close/retraction/media edits lacking confirmed server semantics use explicit linked fallback rather than fake native operations - source protobuf is insufficient proof - cost if wrong: native support can be enabled after permitted real validation.
